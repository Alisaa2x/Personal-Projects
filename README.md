# Alisa's Personal Website

## Introduction
A modern, responsive personal **portfolio website** built using **HTML**, **CSS**, and **JavaScript** to showcase my experience, projects, and contact information.
<img width="1607" height="851" alt="Screenshot 2025-10-06 104701" src="https://github.com/user-attachments/assets/b725c159-da46-42e4-a329-58cd410bba58" />

## About
This website serves as my **personal portfolio**, introducing who I am, my background, professional experiences, and selected projects. It’s designed to be **simple, elegant, and mobile-friendly**, with smooth navigation and an adaptive layout for all screen sizes.

## Features
- 🧍‍♀️ **Profile Section** — Includes name, picture, resume, and LinkedIn & Github link
- 💼 **Experience Section** — Lists internship and technical programs  
- 🧩 **Projects Showcase** — Links to my coding projects and live demos  
- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile  
- 📬 **Contact Section** — Easy access to email and LinkedIn

## Tech Stack
| Technology | Description |
|------------------|----------------------------------------|
| **HTML**        | Structure and layout of the website     |
| **CSS**         | Styling and responsive design           |
| **JavaScript**   | Interactivity (hamburger menu toggle)  |
| **Google Fonts** | Typography styling with *Poppins* font |
